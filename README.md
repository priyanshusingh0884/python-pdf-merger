# 📄 Python PDF Merger

A simple Python application that merges multiple PDF files into a single PDF document using the PyPDF2 library.

## ✨ Features

- Merge multiple PDF files.
- Read PDF documents using PyPDF2.
- Combine PDF pages into one document.
- Save the merged PDF as a new file.

## 🛠️ Technologies Used

- Python
- PyPDF2

## 📦 Installation

Install the required library:

```bash
pip install PyPDF2
```

## ▶️ How to Run

1. Clone this repository.
2. Open the project folder.
3. Place your PDF files in the project directory.
4. Update the PDF filenames in the Python script.
5. Run:

```bash
python main.py
```

The merged PDF will be saved as `merged.pdf`.
